# 통합회원 React 마이그레이션

2025.11 – 2026.05

URL: [https://www.coway.com/](https://www.coway.com/)

## 서비스 내용

---

30만 회원 규모 통합회원의 Keycloak 의존 로그인·회원 화면을 React와 TypeScript 기반 인증 흐름으로 전환한 프로젝트입니다.

- 기존에는 Keycloak FreeMarker 템플릿과 리다이렉트가 인증 단계를 제어했습니다.
- 전환 후에는 신규 API 응답을 기준으로 React 화면이 인증 단계를 직접 제어합니다.
- 일반·SNS·중복 계정 로그인, 본인인증, 비밀번호 변경, reCAPTCHA 흐름을 포함합니다.

## 기술스택

---

- React, TypeScript, Zustand, Zod, Vite, SCSS, Datadog RUM, GA4, Vitest, Cypress, AWS

## 개발내용

---

**인증 흐름 전환**

- Keycloak FreeMarker 템플릿과 리다이렉트에 의존하던 인증 단계를 신규 API 응답 기반의 React 화면 제어 구조로 마이그레이션했습니다.
- 인증 단계별 상태를 Zustand로 관리하고 응답 스키마를 Zod로 검증해 서버 변경에 따른 화면 오류를 사전에 잡았습니다.
- 기존 Keycloak 리다이렉트와 신규 마이그레이션 API의 오류 전달 방식을 비교하고, 토큰·인증 헤더·로그아웃의 책임 범위를 정리했습니다.

**로그인 플로우 안정화**

- 중복 계정 로그인 시 발생하던 400 에러를 응답별 프론트엔드 동작으로 정리해 대응했습니다.
- 카카오 로그인과 First Broker Login 예외를 포함한 SNS 로그인 에러 처리를 개발했습니다.
- 단계(step) 검증과 redirect uri 쿼리 파라미터화를 적용하고, history 조작을 navigate로 통일해 잘못된 단계 진입과 복귀 오류를 막았습니다.
- 일반·SNS·중복 계정 로그인, 본인인증, 비밀번호 변경, reCAPTCHA의 화면 분기와 오류 처리를 프론트엔드 로직으로 재구성해 백엔드 템플릿 의존도와 코드 복잡도를 낮췄습니다.

**약관과 보안 대응**

- GDPR 약관을 정의하고 연동했으며, 약관 조회 로직과 forceLogout 처리를 개발했습니다.
- account-frontend-sdk에 CSRF/XSRF 토큰 대응을 반영했습니다.
- 회원정보 변경 시 비밀번호 확인, IoCare 자동로그인 기본값, 약관 개정을 정기 배포로 반영했습니다.

**운영 안정성과 문서화**

- **QA에서 발견된 예외 케이스를 Vitest와 Cypress 테스트로 전환해 회귀 오류를 막았습니다.**
- 로그인 에러 케이스, SNS 로그인 에러 처리 가이드, 테스트 케이스, 로그인 GA 마이그레이션 문서를 작성해 전환 이후 운영 이슈를 빠르게 추적할 수 있게 했습니다.
- 국내 통합회원 UI 가이드와 FE 네이티브 연동가이드를 작성해 앱과 연동하는 팀이 같은 기준으로 개발할 수 있게 했습니다.
- 기기, OS, 언어별 운영 오류를 추적해 핫픽스로 대응했습니다.

## 성장경험

---

1. 인증 서비스는 정상 플로우보다 예외 상태와 리다이렉트 복귀 처리가 제품 품질을 좌우한다는 점을 다시 확인했습니다.
2. 30만 회원이 쓰는 화면을 전환할 때는 테스트와 문서가 마이그레이션의 실질적인 안전장치가 됩니다.
3. 2023년 Vue 3로 구축했던 서비스를 React로 다시 설계하며 같은 도메인을 두 프레임워크로 비교해 볼 수 있었습니다.
