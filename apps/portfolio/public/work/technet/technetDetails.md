## 개요

KSNET 사내 개발자들이 업무를 공유하고 관련 자료를 올려 개발을 더 효율적으로 진행할 수 있도록 만든 기술 공유 사이트입니다. React와 Redux-Saga로 웹 페이지 화면을 개발하고 사내 API를 연동했습니다.

## 핵심 사례

### 흩어진 개발 자료를 하나의 사이트로

개발에 필요한 문서, 이슈 트래킹, 프로젝트 API 명세서가 여러 곳에 나뉘어 있어 자료를 찾는 데 시간이 들었습니다. 개발 소요 시간을 줄이기 위해 **이 자료들을 하나의 웹 사이트에서 볼 수 있도록 통합했습니다.** 화면 레이아웃과 UI를 구성하고 사내 API를 연동해 자료를 조회하고 올릴 수 있게 했습니다.
