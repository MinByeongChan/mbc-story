## 개요

레거시와 신규 서비스의 회원을 통합하는 30만 회원, DAU 약 5K 규모의 B2C 인증 플랫폼입니다. 코웨이몰과 ioCare(코웨이 IoT 앱) 회원을 통합 관리하며, 회원가입·계정찾기·마이페이지·로그인 화면과 구 회원의 통합회원 전환 기능을 개발했습니다.

## 핵심 사례

### Keycloak 로그인을 로컬에서 재현하는 테스트 환경

Keycloak의 리다이렉트 로그인 방식 때문에 토큰을 유지한 채 로컬에서 테스트하기 어려웠습니다. 각 BE 서비스가 docker로 구성되어 있다는 점에 착안해 Keycloak과 BE 이미지를 로컬에 띄우고, 리다이렉트 로그인과 토큰 발급을 그대로 재현한 환경에서 회원가입·계정찾기·마이페이지 기능을 개발하고 확인했습니다.

연동하는 쪽 입장의 검증 도구도 만들었습니다. React와 Vite로 통합회원 연동 테스트 클라이언트(test-client)를 개발해, 클라이언트별 로그인·회원가입·아이디/비밀번호 찾기 시나리오를 실제 연동 방식대로 검증할 수 있게 했습니다.

**QA 전에 각 개발자가 로컬에서 피처를 먼저 확인하고 연동 이슈를 재현할 수 있게 되어 운영 검증의 안정성을 높였습니다.**

### Vue 3 전환 중 생긴 QA 이슈를 테스트로 고정

Vue 2에서 Vue 3로 업데이트하는 과정에서 이전에 없던 이슈들이 QA에서 발견되었습니다. 레거시로 남아 있던 E2E 테스트를 다시 활성화하고, 유틸 함수는 유닛 테스트로, 로그인·API 관련 이슈는 Cypress interceptor로 검증했습니다. store가 필요한 부분은 Cypress에서 세팅해 실제 브라우저 상황과 같게 만들었습니다.

**발생한 이슈를 케이스별 테스트로 남겨 재발을 막았고,** 이후 QA 이슈를 이전 버전과 비교하며 더 확실하게 처리할 수 있었습니다.

## 그 외 작업

- 코웨이몰·ioCare 회원을 통합회원으로 전환하는 마이그레이션 화면과 필드 검증 개발
- 서비스(clientName)별 언어 고정, 푸터 약관 locale·국가코드 로직, 일본어·영어 번역 적용
- 점유인증·본인인증 프로세스 개발, NICE 본인인증 SDK를 npm 패키지와 CDN으로 제공
- DDD 패턴으로 회원가입·OTP·계정 모델과 Hook을 도메인 단위로 분리해 변경 영향 범위 축소
- WCAG 2.1 기준 반영, iOS Safari·Android WebView·PC 브라우저별 예외 처리 추가
- 미국 신사업 프로젝트의 회원 서비스 초기 구축
- RND 환경 CI/CD 구축과 env 체계 정리, Datadog으로 디바이스·OS·언어별 런타임 오류 추적
