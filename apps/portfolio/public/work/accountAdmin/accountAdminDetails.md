## 개요

코웨이몰과 ioCare 등 여러 서비스의 일반·휴면 회원, 약관, 로그와 관리자 권한을 관리하는 내부 운영 도구입니다. 2021년 입사 직후 킥오프부터 맡아 **806커밋으로 레포 기여 1위**를 기록했습니다.

## 핵심 사례

### 퍼블리싱 없이 약관을 배포하는 에디터

수시로 바뀌는 이용약관을 화면에 반영하려면 매번 퍼블리싱 작업이 필요했습니다. WYSIWYG 에디터를 조사해 CK Editor를 선정하고, 기획이 요구한 heading·anchor·title 스타일과 통합회원 화면과 같은 스타일의 미리보기를 커스터마이징했습니다.

**약관 매퍼를 개발해 별도 퍼블리싱 없이 약관을 작성하고 통합회원 서비스에 배포하는 환경을 만들었습니다.**

### ISMS-P 심사 요구사항을 화면 동작으로

ISMS-P 인증 심사에 대응해 보안 요구사항을 화면 동작으로 옮겼습니다. **세션 유지 기능, 남은 시간 카운트 훅, 로그인 연장 안내 모달을 직접 개발했고,** 심사 항목에 맞춰 권한·로그·개인정보 노출 범위를 점검해 마스킹과 로그 상세 설명을 보완했습니다.

사내 SSO로 코웨이 내부망의 관리자만 접근하도록 설정하고, 권한 없는 사용자의 무한 리다이렉트 문제와 페이지 크롤링 제한도 함께 처리했습니다. 보안 요구사항이 세션 만료와 연장 안내 같은 화면 동작으로 어떻게 이어지는지 직접 구현해 볼 수 있었습니다.

## 그 외 작업

- TypeScript, 라우터, 모달 프로바이더 등 프로젝트 초기 환경과 텍스트·레이아웃 공통 UI 컴포넌트 체계 구축
- 회원·휴면회원 관리(상세보기, 엑셀 다운로드, 검색 필터), 로그 조회(페이징, 태그별 출력), 관리자 설정 화면 개발
- 메뉴별 권한 접근 제어와 관리자 권한 등록·편집 화면 개발
- Redux Toolkit을 도입하고 팀 보일러플레이트를 제공해 상태 관리 간소화
- 모달 컨텍스트를 리듀서와 액션으로 분리해 모달 상태 관리 구조 개선
- AWS S3·CloudFront 조합의 배포 구성(캐시, origin, 실패 페이지 설정)과 2주 스프린트 단위 검증
