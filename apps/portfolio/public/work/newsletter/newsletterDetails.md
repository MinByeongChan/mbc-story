# 뉴스레터

2024.04 – 2025.10

## 서비스 내용

---

코웨이 미국 신사업 고객에게 제품, 프로모션, 브랜드 콘텐츠를 구독 기반으로 전달하기 위한 뉴스레터 페이지입니다.

- 이메일 구독 신청, 구독 완료, 유효성 검증 화면을 제공합니다.
- 글로벌 고객을 고려해 다국어 문구를 적용했습니다.
- 제품과 프로모션 콘텐츠를 빠르게 전달할 수 있도록 단순하고 명확한 신청 흐름을 구성했습니다.

## 기술스택

---

- Vue3, Typescript, Pinia, Vite, SCSS, Tailwind CSS, AWS(S3, CloudFront), VeeValidate

## 개발내용

---

**구독 신청 플로우 개발**

- 이메일 입력, 약관 동의, 구독 완료 화면까지 이어지는 신청 플로우를 개발했습니다.
- 뉴스레터 동의 API와 이메일 유효성 검증을 연동해 잘못된 이메일 제출을 사전에 차단했습니다.
- 퍼블리싱이 모달 형태에서 페이지 형태로 바뀐 것을 반영하고, 컴포넌트를 분리해 체크박스 데이터를 연동했습니다.

**다국어 화면 대응**

- 언어별 경로를 이용해 영어와 한국어 화면을 처리했습니다.
- 미국 신사업 고객 대상 서비스 흐름에 맞춰 영문 문구와 화면 상태를 정리했습니다.
- 다국어 적용 시에도 입력 폼과 완료 화면의 레이아웃이 무너지지 않도록 반응형 UI를 구성했습니다.

**스타일 통합**

- Tailwind로 만든 결과 CSS를 기존 서비스에 적용했습니다.
- 기존 서비스의 Reset CSS와 충돌하던 스타일을 정리해 화면이 의도대로 표시되도록 해결했습니다.

**정적 배포 환경 구성**

- AWS S3와 CloudFront 기반 정적 배포 흐름에 맞춰 빌드 산출물을 운영할 수 있도록 구성했습니다.
- 배포 후 캐시 영향을 고려해 화면 변경 사항이 안정적으로 반영되도록 확인했습니다.

## 성장경험

---

1. 짧은 신청 흐름일수록 입력 검증과 상태 메시지가 사용자 경험에 크게 영향을 준다는 점을 확인했습니다.
2. 글로벌 서비스에서 다국어 문구 길이와 반응형 레이아웃을 함께 고려하는 방식의 중요성을 경험했습니다.
3. 서로 다른 방식으로 만든 스타일을 한 서비스에 합칠 때 Reset CSS 같은 전역 스타일의 영향 범위를 먼저 확인해야 한다는 것을 배웠습니다.
4. 정적 배포 환경에서 캐시와 화면 갱신 시점을 고려하며 운영 안정성을 확인했습니다.
