## 개요

코웨이 미국 신사업 고객에게 제품, 프로모션, 브랜드 콘텐츠를 구독 기반으로 전달하는 뉴스레터 페이지입니다. 이메일 입력부터 약관 동의, 구독 완료까지의 신청 흐름과 영어·한국어 화면을 개발했습니다.

## 핵심 사례

### Tailwind 결과물을 기존 서비스 스타일과 합치기

Tailwind로 만든 결과 CSS를 기존 서비스에 적용하자, 기존 서비스의 Reset CSS와 충돌해 화면이 의도와 다르게 표시되었습니다. 충돌하는 전역 스타일을 정리해 두 스타일이 함께 동작하도록 해결했습니다.

서로 다른 방식으로 만든 스타일을 한 서비스에 합칠 때는 Reset CSS 같은 전역 스타일의 영향 범위를 먼저 확인해야 한다는 것을 배웠습니다.

## 그 외 작업

- 이메일 입력, 약관 동의, 구독 완료 화면으로 이어지는 신청 플로우 개발
- 뉴스레터 동의 API와 이메일 유효성 검증을 연동해 잘못된 이메일 제출을 사전 차단
- 모달에서 페이지 형태로 바뀐 퍼블리싱을 반영해 컴포넌트를 분리하고 체크박스 데이터 연동
- 언어별 경로로 영어·한국어 화면을 처리하고, 문구 길이를 고려한 반응형 레이아웃 구성
- AWS S3·CloudFront 기반 정적 배포와 배포 후 캐시 반영 확인
