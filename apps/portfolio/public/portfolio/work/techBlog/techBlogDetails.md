# 기술블로그

2022.01 – 현재

[Blog](https://mbc-dev-blog.vercel.app)
[Github Repository](https://github.com/MinByeongChan/mbc-devBlog)

## 서비스 내용

- 개발 또는 스터디했던 내용들을 정리해가며 기록하기 위한 기술 블로그입니다.

- 스터디했던 내용들을 정리하면서 2차, 3차 공부를 할 수 있고, 그 내용들을 제것으로 만들고 정리하는 습관을 들이기 위해 블로그를 개설했습니다.

- 티스토리, Gastby 템플릿, Github Page 등 다양한 방식을 사용하여 거듭한 끝에 심플한 디자인을 선택하게 되었습니다.

- 기존 방식은 스타일이 정해져있고, 어느정도 템플릿이 만들어져 있어 나만의 블로그를 처음부터 만들어보고자 새로 개발하게 되었습니다.

## 기술스택

- React, Typescript, Material Ui, Scss

## 성장경험

- Markdown 을 디코딩하여 React Component로 변환하는 작업을 수행했습니다.

- Firebase 스토리지를 사용하여 블로그 글을 게시하기도 했습니다. 현재는 로컬에서 관리하고 있습니다.

- 이전 Nextjs 버전을 SPA 버전으로 마이그레이션 하며 장점과 단점을 명확하게 알 수 있었습니다.
  - Nextjs의 지식이 없었을때라, 유지보수가 어렵다는 이유로 마이그레이션을 했습니다.
  - 하지만, SPA로 넘어오며 SSR의 장점인 SSO를 관리하기 어려운 이슈가 발생했습니다.
  - 컨텐츠 로드 속도 또한 느려졌습니다. http 요청을 통해 가져오므로 로딩이 발생했기 때문입니다. 이는 이전에는 없었던 약간의 버벅임이 생겼습니다.
  - 유지보수 측면에서는 좋으나, 성능상 이점이 없는것으로 느껴 향후 모노레포로 마이그레이션하여 Nextjs로 전환할 예정입니다.
