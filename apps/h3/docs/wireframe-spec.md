# H3 그리드 테스트 페이지 와이어프레임 스펙

Figma, Photoshop, Zeplin 등 디자인 도구에서 참고할 수 있는 와이어프레임 명세입니다.

## 파일

- **wireframe-h3-grid-test.html** – 브라우저에서 열어 확인 가능한 인터랙티브 와이어프레임
  - Figma: 브라우저에서 스크린샷 후 이미지로 임포트
  - Zeplin: HTML 또는 스크린샷 업로드
  - Photoshop: 스크린샷 후 레이어로 작업

## 레이아웃

| 영역 | 크기 | 설명 |
|------|------|------|
| Header | 60px | 타이틀 "VWorld + H3 WebGL 예제" |
| SNB | 280px | 좌측 사이드바, 스크롤 가능 |
| Map | flex: 1 | VWorld 지도 + 레이어 |

## SNB 섹션 (우선순위별)

### 1순위 (테스트에 바로 유용)

| 섹션 | 구성 요소 |
|------|----------|
| H3 Resolution | Overlay resolution 드롭다운, 선택 영역 resolution 드롭다운 |
| 레이어 제어 | GeoJSON/Overlay H3/선택 영역 H3 체크박스, Opacity 슬라이더, 선택 영역 클리어 버튼 |
| 지역 검색 | 검색 입력창, "검색 결과 영역 자동 선택" 체크박스 |
| 선택 영역 | 선택 없음 메시지, 선택 시 지역명/좌표/H3 셀 개수 표시 |
| H3 셀 호버 툴팁 | 지도 위 마우스 오버 시 H3 인덱스, resolution, parent/children 표시 |

### 2순위 (디버깅·분석용)

| 섹션 | 구성 요소 |
|------|----------|
| H3 유틸리티 | H3 인덱스 입력 + 이동/하이라이트 버튼, Lat/Lng 입력 + 좌표→H3 변환, K-ring 시각화 체크박스 |
| 데이터 내보내기 | H3 인덱스 CSV/JSON 버튼, 통계 내보내기 버튼 |

### 3순위 (고급 테스트)

| 섹션 | 구성 요소 |
|------|----------|
| 성능/비교 | Compact vs Non-compact 탭, Resolution 비교 탭, 셀 개수/렌더 시간 표시 |
| 스타일 | 색상 모드(지역별/단일), 테두리 두께/색상 |
| 기타 | 반경(km) 입력 + gridDisk 생성, URL 상태 공유 |

## 레이어 구조

1. **GeoJSON Base** – 시군구 폴리곤 (토글 가능)
2. **Overlay H3** – 전체 시군구 영역 헥사곤 (토글 가능)
3. **선택 영역 H3** – 클릭한 시군구 헥사곤 (초기 2개, 클릭 후 3개, 토글 가능)
