## 3. 브랜드·테마 요구

### 3.1 다크 모드

| 항목 | 결정 |
| --- | --- |
| 지원 범위 | 전역 / 일부 화면만 / 미지원 |
| 전환 방식 | 시스템 선호 / 토글 / URL·쿠키 |
| 구현 훅 | 예: `data-theme`, `class="dark"`, Panda `conditions` |

### 3.2 멀티 테넌트·화이트라벨

| 항목 | 결정 |
| --- | --- |
| 필요 여부 | 예 / 아니오 |
| 가변 요소 | 로고, 프라이머리 컬러, 폰트, 일부 카피 등 |
| 토큰 전략 | 테넌트별 시맨틱 오버레이 vs 별도 빌드 |

브랜드가 여러 개면 **프리미티브는 공유**하고 **시맨틱/테마 레이어**에서만 분기하는지 명시합니다.
